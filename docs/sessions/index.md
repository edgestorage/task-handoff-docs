# 使用 AI 会话

AI 会话是在某个实例和固定工作目录中执行的一次 AI 工作任务。

TaskHandoff 当前主要支持 **Codex** 和 **OpenCode**。新建会话时先选择 Agent，再选择与它兼容的模型。Codex 与 OpenCode 的能力差异见 [Codex 与 OpenCode](/agents/)。

## 新建会话

1. 打开一个运行中的实例。
2. 在 AI 区域选择“新建 AI 会话”。
3. 选择 Agent、模型和工作文件夹。
4. 设置思考程度与权限模式。
5. 输入任务并发送。

会话创建后工作目录不会自动改变。需要在另一个 worktree 工作时，应从仓库环境中在目标 worktree 新建会话。

## 权限模式

不同 Agent 支持的选项可能不同，常见模式包括：

- “询问”：敏感操作需要你明确批准，适合日常使用；
- “自动审批”：减少审批中断，只应在可信工作区使用；
- “完全访问”：允许更广泛的文件和系统操作，只应用于隔离且可恢复的环境。

::: warning 最小权限
不确定时保持“询问”。在包含生产凭据、个人文件或重要未备份数据的环境中，不要启用完全访问。
:::

## 发送消息

编辑器支持普通文本、命令、上下文提及和附件。输入界面配置的命令字符可以打开命令菜单；上下文字符可搜索并引用文件等资源。

AI 正在执行时，新消息可以根据当前模式立即发送、追加到当前任务或进入队列。使用“停止”会终止当前运行，但已经写入磁盘的修改不会自动撤销。

## 阅读执行过程

会话时间线会显示：

- 用户消息与 AI 回复；
- 思考、工具调用和文件编辑等活动；
- 等待审批、运行中、空闲或失败状态；
- 附件、子 Agent 和最终结果。

当界面断线重连时，TaskHandoff 会重新获取权威会话快照。短暂显示“正在重连”不代表后台任务已经停止。

## 简洁模式与对话模式

AI 会话详情提供“简洁”和“对话”两种查看模式，可以从会话右上角的更多菜单中切换。

::: tip TaskHandoff 特色：简洁模式
简洁模式是 TaskHandoff 的默认和特色会话体验。它聚焦当前选中的一个任务回合，只保留完成当前判断所需的提示词、AI 回复、实时工具活动、审批、消息队列和子 Agent 状态，大幅减少长会话中历史消息与重复过程造成的干扰。
:::

### 简洁模式

适合日常工作和同时监管多个 AI 任务：

- 默认只展示当前回合，而不是连续铺开全部历史消息；
- 任务运行时仍显示当前工具、编辑、审批和队列状态；
- 可以在不同回合之间切换，需要时再查看之前的任务结果；
- 长会话不会因为大量历史内容挤占当前工作区域。

简洁模式不是摘要替代品，也不会删除或压缩服务端会话数据。切换回对话模式后，仍可查看完整历史。

### 对话模式

对话模式按时间顺序展示整个会话中的用户消息、AI 回复和各回合活动，适合：

- 回顾任务是如何逐步推进的；
- 查找较早的提示词、回复或工具执行记录；
- 审计审批、失败和重试过程；
- 需要理解跨多个回合的上下文时。

模式选择会保存在当前浏览器中，并用于之后打开的会话。它只影响展示方式，不会改变 Codex、OpenCode 的运行状态、模型上下文或磁盘文件。

## 管理多个会话

可以从实例侧栏、AI 看板或 Story 中切换会话。关闭会话会停止仍在进行的工作；“关闭所有会话”会影响当前实例中的全部会话，确认前请检查是否还有任务运行。

桌面端支持把实例打开到独立窗口。浏览器阻止弹窗时，需要先允许当前站点打开弹窗。

## 会话设置

在“实例设置 → AI”中可以设置新会话默认值。Codex 还支持输出详细程度、沟通风格及多 Agent 等托管选项；OpenCode 使用自己的模型、推理变体和权限配置。修改不会重写已运行会话。

## 使用建议

- 在任务开头说明目标、约束和验收标准；
- 大任务拆成可验证的阶段，及时检查实际文件变化；
- 让 AI 运行测试，但不要仅凭文字回复判断任务完成；
- 提交或发布前使用“仓库 → 变更”复核差异；
- 重要结果写入项目文件或 Story 文档，不要只保留在聊天记录中。
