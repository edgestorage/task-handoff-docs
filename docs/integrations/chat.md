# 聊天桥接

聊天桥接把 Telegram、微信、钉钉和飞书/Lark 消息接入 TaskHandoff，并路由到指定实例的 AI 会话。

## 创建桥接

1. 打开“设置 → 聊天”。
2. 选择“添加桥接”和聊天渠道。
3. 填写名称及平台提供的 App ID、Client ID、Token 或其他所需凭据。
4. 配置默认目标和允许使用的用户。
5. 保存后检查桥接状态。

不同平台需要的回调、机器人权限和连接参数不同，应以界面字段和平台后台为准。Secret 保存后不会显示完整值。

## 路由与访问

聊天入口、命令解析和路由由 Control Plane 管理。一个入口不能同时绑定多个 Control Plane、多个实例或两者组合。

限制允许用户，并为默认目标选择可信实例。聊天消息可能触发 Agent 读写工作区，其权限最终受目标会话和实例配置约束。

## 公开访问地址

“设置 → 基础 → 公开访问地址”决定聊天消息中的控制面板链接。应填写用户实际可访问的 HTTPS 地址，并验证登录和 WebSocket 均可工作。

## 运行与故障

桥接状态异常时检查平台凭据、回调配置、网络和聊天网关日志。修改草稿未保存时关闭会丢失变更。删除桥接会立即停止该聊天入口，但不会删除已经存在的 AI 会话。

## 安全建议

- 只允许明确的用户或群组；
- 不在聊天中发送 API Key、Git Token 或一次性节点令牌；
- 高权限操作继续使用“询问”审批；
- 定期轮换机器人凭据并移除不用的桥接；
- 公网控制面板必须启用认证和 HTTPS。
