# 设置与安全

设置页是否显示某些区域取决于当前账号权限。节点、镜像、模型和项目属于日常资源配置；用户、登录源、云连接和凭据通常需要管理员权限。

## Git 凭据

“设置 → Git 凭据”支持按远端范围管理 HTTPS Token 和 SSH 私钥。凭据范围由协议、主机、可选端口和区分大小写的仓库路径前缀组成。

创建 Git 实例时，凭据默认只用于首次 clone。启用“在此实例中保留”后，该实例同一运行用户下的 Agent、终端、应用和仓库操作都能对匹配远端使用凭据。

::: warning 保留授权的边界
远端 scope 用于避免误选凭据，不是抵御实例内恶意进程的安全边界。只向可信实例授予长期凭据，并使用权限尽可能小的专用 Token。
:::

SSH 凭据必须提供固定的 `known_hosts` 信息。认证失败后，系统只会显示安全分类；调整凭据或实例授权后，需要手动重试原 Git 操作。

## 用户与权限

管理员可以在“设置 → 用户与权限”中：

- 创建、停用和恢复本地用户；
- 分配系统角色或自定义角色；
- 限制用户可访问的节点和实例；
- 重置本地密码并撤销登录会话；
- 配置 OIDC 或 GitHub 登录源；
- 审批或拒绝外部身份注册。

重置密码会生成一次性临时密码，并使用户现有会话失效。通过安全渠道传递临时密码，不要将其写入工单或公共消息。

## 账号与设备

在账号与安全区域修改自己的密码后，当前设备以外的登录会话会退出。“移动设备会话”列出当前账号已登录的设备，撤销某个会话只会让对应设备退出。

“Thandoff Cloud → 已信任设备”列出本 Control Plane 明确固定、允许通过云中继访问的设备。撤销固定会立即关闭该设备的云端活动中继会话，但不会退出其 Thandoff 账号登录；账号登录会话仍需在对应账号安全设置中管理。

## 节点安全

Node Agent 的公网地址必须使用 HTTPS，并通过一次性配对 Token 建立连接。配对完成后不要重复保存 Token。

本机节点即使调整 TCP listener，仍会保留内部 Unix socket。把 listener 从 `127.0.0.1` 改为 `0.0.0.0` 会扩大网络暴露范围，必须同时配置主机防火墙、TLS 和访问控制。

## 实例目录

“设置 → 实例”汇总所有节点上的实例，可以按名称、ID、节点、项目和镜像搜索，并按节点、状态或运行时筛选。结果行可以直接打开实例设置，不必先回到对应的实例看板。

某个节点暂时离线或无法提供最新目录时，页面会提示列表可能不完整。恢复节点连接后重试，不要把缓存结果当作跨节点的完整权威快照。

## 云平台节点与信任

节点可以绑定到 Thandoff 账号，供同一账号内的其他 Control Plane 通过云中继使用。节点首次接受某个 Control Plane，或后者身份、公钥发生变化时，会产生“节点 Control Plane 信任”审批。

批准前核对节点上报的显示名称、指纹和比较码。当前 Control Plane 不能从同一个节点界面撤销对自己的信任，需要在节点上运行 `task-handoff-node-agent trust`；其他 Control Plane 的信任可以从节点详情撤销。共享节点使用权可能带过期时间，过期后不能建立新连接。

完整的添加、审批和撤销流程见[节点管理](/zh/admin/nodes#云平台节点与信任)。

## 聊天与公开地址

聊天入口可以把 Telegram、钉钉、微信或飞书/Lark 消息路由到指定实例。同一个聊天入口不能同时绑定多个控制平面或实例。

配置“公开访问地址”后，从聊天消息打开会话时会使用该外部地址。确保它使用 HTTPS 且只暴露预期的控制面板。

## 外观和编辑器

“设置 → 基本 → 外观”可以调整主题、语言、排队消息位置、远程桌面卡片展示方式和 AI 编辑器快捷字符。主题支持“跟随系统”“浅色”和“深色”；跟随系统会使用当前操作系统或桌面客户端的配色，并随系统切换而更新。

远程桌面卡片可以选择打开浮动窗口，或在会话内就地展开。外观偏好通常保存在当前浏览器或桌面客户端，不会改变实例、AI 会话或服务器数据。

## 远程桌面与 TURN

拥有设置管理权限的管理员可以在“设置 → 远程桌面”配置“自定义 TURN”，为通过此 Control Plane 打开的远程桌面提供中继：

- 每行填写一个 `turn:` 或 `turns:` 地址，UDP/TCP 使用 `turn:`，TLS 使用 `turns:`；
- 使用用户名和密码认证，或 coturn REST 共享密钥；
- 凭证加密保存在 Control Plane，仅向会话参与端下发；
- 使用共享密钥时，Control Plane 主机和 TURN 服务器必须保持时间同步；
- 保存后，新建连接和凭证续期使用新配置。

云端 TURN 尚未就绪时会显示为不可用，这不影响自定义 TURN 或 WebSocket 兼容通道。远程桌面的安装、画面选择、输入控制和连接诊断见[远程桌面](/zh/workspace/remote-desktop)。

## 更新

服务器完整安装可以在“设置 → 基本 → 服务器更新”中更新 Control Plane、Node Agent 和受控实例运行时。节点详情中的“更新”页用于检查和执行节点 rollout。

生产环境优先使用 `stable` 渠道。更新前检查活跃工作；受控实例运行时更新可能在有限等待后重启实例。停止的实例不会仅为更新而自动启动，而是在下次正常启动前安装目标版本。

受管应用和“远程桌面”组件由实例的应用管理独立更新，不随服务器或受控实例版本自动升级。组件缺失、需要修复或需要获取新版本时，从“实例设置 → 应用”安装或更新；该操作与 Control Plane、Node Agent 更新是两条独立流程。
