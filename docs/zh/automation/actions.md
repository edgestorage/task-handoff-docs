# 预设动作

预设动作保存一套可重复执行的 AI 会话配置和提示词模板。它适合代码检查、依赖更新、日报汇总和固定诊断等重复任务。

## 动作配置

一个动作可以包含：

- 标题和提示词模板；
- 目标实例；
- Codex 或 OpenCode Agent；
- 模型与思考程度；
- 权限模式；
- 工作文件夹；
- 当前目录或 Worktree 等 Git 模式；
- 消息发送模式。

也可以从当前 AI 会话选择“保存为预设动作”，复用已经验证过的会话配置和提示词。

## 权限

动作会在每次运行时复用保存的权限模式。保存“完全访问”意味着以后通过该动作创建的会话也会获得相同权限。固定自动化优先使用最小权限，并让高风险操作保持询问。

## 运行动作

1. 在 Story 中选择预设动作。
2. 检查目标实例是否在线。
3. 确认 Agent、工作目录和权限。
4. 运行并创建新的 AI 会话。
5. 从 Story 会话列表查看执行过程和结果。

Story 所属节点没有可用目标实例时，动作不能运行。修改或删除目标实例后，应同步更新相关动作。

## Codex 与 OpenCode

默认动作通常使用 Codex，也可以明确选择 OpenCode。Codex 动作可以使用其托管思考程度和权限配置；OpenCode 动作应选择兼容的模型 Provider。不要假设同一个模型名称能同时用于两个 Agent。

## 提示词模板建议

模板应明确输入来源、输出位置、禁止事项和验收标准。自动运行的模板不要包含一次性 Secret，也不要依赖“上次会话里提到的内容”。
