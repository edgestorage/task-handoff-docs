# 认识 TaskHandoff

TaskHandoff 是一个自托管的 AI 工作空间控制面板。你可以用它在不同计算机上创建隔离的开发实例，主要运行 **Codex** 和 **OpenCode**，并统一查看会话、文件、代码变更和运行状态。

## 它解决什么问题

当 AI 开发工作分散在多台机器、多个项目和多个聊天入口时，TaskHandoff 提供一个集中入口：

- 管理本机和远程机器上的运行节点；
- 为 Git 仓库或本地目录创建隔离工作空间；
- 安装、启动和停止受管应用；
- 创建 Codex 或 OpenCode AI 会话并实时查看执行进度；
- 检查文件、Git 变更、分支和 worktree；
- 通过 Story、预设动作和触发器组织重复工作；
- 从 Web、桌面端、移动端或聊天平台访问任务。

## 基本概念

### 控制面板

你日常操作的 Web 界面。它保存用户、节点、项目、模型、凭据和聊天入口等管理信息。

### 节点

运行 Node Agent 的计算机。节点负责管理本机资源、目录以及受管实例的生命周期。一套控制面板可以连接多个节点。

### 实例

承载实际工作区和 AI 工具的运行环境。Docker Runtime 支持在同一节点上运行多个隔离实例；Local Runtime 使用宿主机环境，同一宿主用户只能运行一个本地实例。

### AI 会话

在实例中运行的一次 AI 工作任务。TaskHandoff 主要支持 Codex 与 OpenCode。会话绑定固定工作目录，可以发送消息和附件，并查看工具调用、审批和最终结果；部分高级能力因 Agent 而异。

### Story

用于组织一组相关文档、AI 会话、预设动作和自动化任务的工作单元。适合长期需求、专题研究或持续维护任务。

## 系统如何协作

```text
浏览器 / 桌面端 / 移动端 / 聊天平台
                    |
                    v
               Control Plane
                    |
                    v
                Node Agent
                    |
                    v
            Controlled Instance
```

控制面板短暂离线不会自动停止 Node Agent 已经管理的 Docker 实例。实例生命周期由节点负责，控制面板恢复后会重新同步状态。
