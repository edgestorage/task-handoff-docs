# 认识 TaskHandoff

TaskHandoff 是一个免费、开源、可自托管的 AI 远程工作控制面板。你可以从 macOS、Windows、Linux 桌面客户端或浏览器远程接入，在不同计算机上创建隔离工作区。当前受管 AI 会话支持 **Codex** 和 **OpenCode**，并统一查看会话、文件、代码变更和运行状态。

## 适用场景

- 有多台工作站或服务器，希望用一个控制面板统一接入，并允许 Agent 在这些设备上工作；
- 需要随时从桌面端、浏览器、移动端或聊天入口写代码、查看进度和管理服务器；
- 希望把 Agent 跑在隔离容器中，并为后续 Kubernetes 运行时保留统一的使用路径。

## 主要方向

- **一个入口**：统一管理所有连接的设备、工作空间和 AI 会话；
- **多终端接入**：通过桌面端、浏览器、移动端和聊天入口进行远程协作；
- **面向大规模场景的服务器管理**：在一个 Control Plane 中集中呈现设备生命周期和运维状态。

## 当前支持范围

- **AI 内核**：当前仅支持 Codex 和 OpenCode。Claude 只在部分既有镜像或配置中保留兼容入口，不属于当前首选的受管内核。
- **远程桌面**：支持窗口级画面共享，也支持整桌面、单个应用和自定义区域；会话预览默认只读。
- **实例运行时**：当前支持 Docker 容器实例，同时提供本机 Local Runtime。
- **Kubernetes**：运行时支持仍在开发中，尚不是受支持的部署目标。

## 云服务与安全

TaskHandoff 可以完全自托管，也可以绑定可选的 Thandoff Cloud，从公网或移动网络随时访问自己的 Control Plane。云中继负责账号目录、连接协调和加密流量转发，不持有工作区内容，也不能代替管理员批准设备访问。

- **官方账号**：支持邮箱与密码、Google/GitHub/Apple OAuth、邮箱验证、TOTP/恢复码和 Passkey；可查看并撤销登录设备，敏感操作需要最近身份验证；
- **端到端加密**：Relay 只转发密文帧与路由/计量标识，不保存明文请求、AI 会话、文件或终端内容；
- **中国与全球节点**：中继节点按客户端位置就近接入，降低跨地域远程工作的延迟；
- **单一主数据区域**：账号、绑定、共享和审计记录保存在一个 home data region，不做跨区域复制或自动故障转移；
- **免费远程访问**：远程工作本身免费；中继流量额度只用于防滥用，合理使用可免费提升。

通过云中继访问 Control Plane 时，客户端还会校验 Control Plane 固定指纹、设备私钥签名和本地批准。云端可以中断或延迟连接，但无法解密业务内容或替管理员批准设备。完整流程见[远程访问](/zh/integrations/remote-access)和[通过 Thandoff 账户访问](/zh/integrations/thandoff-account)。

## 它解决什么问题

当 AI 开发工作分散在多台机器、多个项目和多个聊天入口时，TaskHandoff 提供一个集中入口：

- 管理本机和远程机器上的运行节点；
- 为 Git 仓库或本地目录创建隔离工作空间；
- 安装、启动和停止受管应用；
- 创建 Codex 或 OpenCode AI 会话并实时查看执行进度；
- 检查文件、Git 变更、分支和 worktree；
- 通过 Story、预设动作和触发器组织重复工作；
- 用 `thctl` 命令行或 Agent Skill 直接操作控制面板；
- 从 Web、桌面端、移动端或聊天平台访问任务。

## 基本概念

### 控制面板

你日常操作的 Web 界面。它保存用户、节点、项目、模型、凭据和聊天入口等管理信息。

### 节点

运行 Node Agent 的计算机。节点负责管理本机资源、目录以及受管实例的生命周期。一套控制面板可以连接多个节点。

### 实例

承载实际工作区和 AI 工具的运行环境。Docker Runtime 支持在同一节点上运行多个隔离实例；Local Runtime 使用宿主机环境，同一宿主用户只能运行一个本地实例。

### AI 会话

在实例中运行的一次 AI 工作任务。TaskHandoff 当前支持 Codex 与 OpenCode 作为受管 AI 内核。会话绑定固定工作目录，可以发送消息和附件，并查看工具调用、审批和最终结果；部分高级能力因 Agent 而异。

### 命令行与 Agent Skill

除了在界面里操作，也可以用 `thctl` 命令行客户端操作同一个控制面板。给 Codex、OpenCode 等 Agent 安装 TaskHandoff Skill 之后，Agent 也能自己调用 `thctl`，安装方式见 [thctl Skill 安装](./thctl-skill)。

### Story

用于组织一组相关文档、AI 会话、预设动作和自动化任务的工作单元。适合长期需求、专题研究或持续维护任务。

## 系统如何协作

```text
浏览器 / 桌面端 / 移动端 / 聊天平台
                    |
                    v
               Control Plane
                    |
                    v
                Node Agent
                    |
                    v
            Controlled Instance
```

控制面板短暂离线不会自动停止 Node Agent 已经管理的 Docker 实例。实例生命周期由节点负责，控制面板恢复后会重新同步状态。
