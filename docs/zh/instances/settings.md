# 实例设置

实例设置独立于全局“设置”。可以从实例标题、实例菜单或“设置 → 节点 → 实例”打开，关闭后不会改变全局设置的位置。

## 常规

常规页显示实例 ID、状态、节点、运行时、镜像、工作区、连接、协议和构建信息。这里还可以控制是否在实例可访问时自动导入 Agent 配置。

自动导入适合个人可信环境。共享实例中应先检查导入内容，避免把本地账号配置或不适用的默认值带入其他工作区。

## AI 与附件

AI 设置包含新会话默认权限、附件保留时间和普通文件上传上限。图片使用独立大小限制。

将附件保留天数调小，可能立即删除已经过期的附件内容；消息元数据仍可能保留。修改前先保存仍需使用的文件。

## Codex 设置

Codex 提供额外的托管选项：

- 输出详细程度和沟通风格；
- 默认思考程度；
- Codex Home 目录；
- 是否允许多 Agent；
- 最大并发子 Agent 数；
- 子 Agent 默认模型与思考程度。

这些选项针对 Codex。OpenCode 使用其对应模型、权限和会话配置，不应假设两者字段完全相同。

## 模型

Codex 与 OpenCode 分别选择模型。模型可使用“全局默认”、控制平面模型或当前节点的本地模型。保存前，系统会把控制平面模型安全同步到实例所属节点；公开实例数据只保存模型 ID 和 revision，不包含 API Key。

模型修改不会立即重启实例，在下次启动或重启后生效。已删除、停用或属于其他 Agent/节点的旧选择会显示为不可用，应明确替换。

## 应用

应用页显示受控实例报告的权威清单，包括已安装、可安装、不支持或需要处理的应用。安装/卸载任务可能需要系统权限，并提供实时输出。

“自定义启动器”只注册实例中已经存在的程序，不能用来执行任意安装命令。

## Git 凭据

实例 Git 授权决定 Agent、终端、应用和仓库工具能否对匹配 remote 使用保留凭据。系统会显示唯一匹配、无匹配、冲突或缺少 SSH host key 等状态。

授权或撤销在 Node Agent 上生效，不要求实例在线。详细安全边界见[Git 凭据](/zh/security/git-credentials)。
