# 常见问题

## TaskHandoff 支持哪些 AI Agent？

当前受管 AI 内核为 **Codex** 和 **OpenCode**。两者都能创建和控制 AI 会话；Codex 具有更深入的托管设置、上下文提及和多 Agent 集成，OpenCode 使用其会话与模型生态。Claude 只在部分既有镜像或配置中保留兼容入口，不属于当前首选的受管内核。

## 关闭网页会停止 AI 任务吗？

不会。任务运行在受控实例中。重新打开页面后会恢复权威状态。删除或停止实例、关闭会话、Node Agent 停止等操作才可能中断任务。

## 简洁模式会丢失历史消息吗？

不会。简洁模式只聚焦当前任务回合，用更少的消息干扰呈现提示、结果和正在进行的活动，是 TaskHandoff 的默认特色体验。切换到“对话”即可查看完整历史；模式切换不会修改会话或 Agent 上下文。

## 停止 Control Plane 会停止实例吗？

普通 Control Plane 停止不会连带停止 Node Agent 管理的 Docker 实例。控制面板恢复后会重新同步。

## Docker Runtime 和 Local Runtime 怎么选？

需要多实例和隔离环境时选择 Docker；需要直接使用宿主工具或目录时选择 Local。一个宿主用户只能有一个 Local Runtime 实例。

## 为什么远程桌面打不开或只能看不能操作？

先确认页面使用 HTTPS、`localhost` 或管理员批准的局域网地址，并检查实例是否已安装、启用远程桌面组件。macOS 宿主还需要“屏幕录制”和“辅助功能”权限。

会话卡片和浮动预览默认只读，进入完整远程桌面后才能启用输入。若提示其他查看者正在控制，只能请求控制权，不能同时输入。窗口关闭或画面来源失效时也需要重新选择画面。详见[远程桌面](/zh/workspace/remote-desktop)。

## 远程桌面一定要配置 TURN 吗？

不一定。远程桌面优先尝试 WebRTC 直连，不能直连时使用 TURN 中继，WebRTC 无法建立时还可回退到 Control Plane 的 WebSocket 兼容通道。只有经常直连失败、频繁回退到 WebSocket，或网络明确限制 UDP 时，才需要优先检查并配置 TURN。

## 远程桌面组件会随实例更新吗？

不会自动跟随。远程桌面组件和受管应用独立发布，需要在“实例设置 → 应用”中安装、更新或修复，再回到“实例设置 → 远程桌面”确认启用。组件更新期间远程桌面可能暂时不可用。

## 远程桌面可以同步剪贴板吗？

可以，但只支持文本。不要把密码、Token 或长期凭证留在共享剪贴板中。

## 为什么模型修改后没有立即生效？

实例模型分配通常在下次启动或重启时生效。已有 AI 会话不会被重写，应重启实例后创建新会话。

## 为什么没有仓库入口？

当前会话必须有可访问的工作目录，并且目录位于 Git worktree 中。实例还需要安装 Git。

## 保留 Git 凭据安全吗？

Secret 不会直接复制进实例，但同一实例用户下的 Agent、终端和应用都能通过代理使用授权凭据。只在可信实例中保留最小权限凭据。

## 删除实例后能恢复吗？

选择“同时删除实例数据”后不能恢复。保留数据时会显示 volume 名称，但需要管理员手动恢复，系统不会自动重新挂载。

## 移动端为什么不能创建实例？

移动端聚焦正在运行的会话和实例操作，不承担基础设施、Secret 和完整生命周期管理。请使用 Web 或桌面端创建实例。

## 页面一直显示重连怎么办？

检查浏览器到 Control Plane 的网络，并确认反向代理支持 `/api/events` WebSocket。重连不代表后台 Agent 已停止。

## 可以让 Agent 自己操作 TaskHandoff 吗？

可以。装好 CLI 和 `thctl` Skill 之后，Codex、OpenCode 等 Agent 就能用命令行读取控制面板状态、创建实例和 AI 会话、排查故障。安装方式见 [thctl Skill 安装](/zh/guide/thctl-skill)。
