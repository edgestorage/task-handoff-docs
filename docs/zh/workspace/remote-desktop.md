# 远程桌面

远程桌面让你在浏览器、桌面端或移动端查看并控制实例环境中的图形桌面，不需要直接连接宿主机。它适合必须依赖 GUI 的验证、桌面应用操作和窗口排查。

::: info 权限边界
远程桌面仍使用当前 Control Plane 账号和实例权限。它不会绕过用户、角色、节点或实例访问范围，也不会替代实例内的审批和文件权限。
:::

## 前置条件

- 通过 HTTPS、`localhost` 或已获准的局域网地址打开 Control Plane；
- 实例平台受支持：macOS Intel/Apple Silicon、Linux x64/arm64、Windows x64；
- 实例已安装“远程桌面”组件，并在“实例设置 → 远程桌面”中启用；
- 实例运行时提供可捕获的桌面或窗口环境；
- macOS 宿主已授予“屏幕录制”和“辅助功能”权限。

远程桌面需要安全的浏览器上下文。通过普通 HTTP 访问远程地址时，界面会拒绝建立信令连接；请改用 HTTPS 或受信任的本地地址。

## 安装并启用组件

1. 打开实例的“设置 → 远程桌面”。
2. 组件未安装时选择“前往应用页”。
3. 在“应用”中安装或更新“远程桌面”组件。
4. 返回“远程桌面”，选择“启用桌面”。
5. macOS 宿主按提示请求“屏幕录制”和“辅助功能”权限，完成后选择“重新检查”。

组件安装、更新和修复是应用任务，可以关闭设置窗口；任务会在实例中继续执行。组件更新期间远程桌面可能暂时不可用。

“远程桌面”组件独立于受控实例版本发布，可以单独安装或更新，不必等待一次完整的实例版本升级。如果界面提示协议或平台不兼容，再同步更新节点和受控实例。

## 打开远程桌面

可以从以下位置打开：

- 实例详情或 AI 会话操作菜单中的“打开远程桌面”；
- AI 会话或 Story 资源栏中的远程桌面入口；
- 移动端 AI 会话的资源菜单或远程桌面卡片。

首次打开需要选择画面。每个查看者可以独立选择整桌面、单个窗口、某个应用或自定义区域；具体类型是否可用取决于宿主环境。保存过的窗口关闭或失效时，需要重新选择画面。

## 预览与控制

会话中的远程桌面卡片和浮动预览默认是只读画面。点击画面打开完整远程桌面后，才能启用输入和剪贴板。

支持的操作包括：

- 启用或停止键盘、鼠标输入；
- 切换到系统键盘或内置虚拟键盘，使用组合键；
- 直接触摸或触控板鼠标模式；
- 启用文本剪贴板，在本机和远端之间发送或读取文本；
- 全屏、停止会话和强制停止；
- 调整分辨率上限、帧率上限和采集精度。

多位查看者可以同时观看同一实例，但同一时间只有一位查看者控制输入。其他人看到“其他查看者正在控制”时，可以选择“请求控制”。控制权空闲后即可启用输入。

## 连接方式与质量

远程桌面优先使用 WebRTC P2P 直连；无法直连时可经 TURN 中继，WebRTC 无法建立时还可回退到 Control Plane 的 WebSocket 兼容通道。

- 至少保留一种连接方式；
- 关闭 WebSocket 兼容通道后，WebRTC 失败会直接断开；
- 网络受限时，分辨率和帧率可能自动降低；
- 连接信息会显示当前路径、延迟、接收码率、编码、查看者和会话详情。

如果经常回退到 WebSocket，说明当前网络不允许所需的 WebRTC/UDP 路径。可以在 Control Plane 配置 TURN，或调整实例网络的 NAT、防火墙和代理策略。

## 配置 TURN

管理员可以在“设置 → 远程桌面 → 自定义 TURN”配置中继：

1. 启用自定义 TURN。
2. 每行填写一个 `turn:` 或 `turns:` 地址，UDP/TCP 与 TLS 使用不同前缀。
3. 选择用户名和密码，或 coturn REST 共享密钥。
4. 保存后新建连接会使用该配置。

凭证加密保存在 Control Plane，只下发给会话参与端。使用共享密钥时，Control Plane 和 TURN 服务器必须保持时间同步。云端 TURN 尚未就绪时会显示为不可用，不影响自定义 TURN 或 WebSocket 兼容通道。

## 安全建议

- 只在可信实例和可信网络中启用远程桌面；
- 只需要查看时关闭输入，避免误操作；
- 优先共享单个窗口、应用或区域，而不是整个桌面；
- 操作完成后停止远程桌面会话；
- 剪贴板只支持文本，不要把密码或长期凭证留在共享剪贴板中；
- 不要把远程桌面当作绕过 Control Plane 认证、实例权限或审批的入口。

## 常见问题

| 现象 | 优先检查 |
| --- | --- |
| 显示“远程桌面不可用” | 组件是否安装、实例是否启用、平台是否支持、实例是否需要更新 |
| 页面提示需要受信任地址 | 改用 HTTPS、`localhost` 或管理员批准的局域网地址 |
| macOS 能连接但没有画面 | 检查“屏幕录制”权限并重新检查 |
| 能看画面但无法操作 | 检查“辅助功能”权限、输入是否启用、是否被其他查看者控制 |
| 画面来源不可用 | 重新选择窗口、应用或桌面；确认窗口没有被关闭 |
| TURN 不可用或连接超时 | 检查 TURN 地址、凭证、防火墙、网络和时钟同步 |
| 频繁切换 WebSocket 兼容模式 | 检查 WebRTC/UDP、NAT、代理和 TURN 配置 |

更多网络入口要求见[让 Control Plane 可远程访问](/zh/integrations/public-control-plane)，组件安装见[应用与终端](/zh/workspace/apps-terminal)。
