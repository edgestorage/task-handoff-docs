# 跨端能力矩阵

TaskHandoff 的 Web、桌面端和移动端共享同一 Control Plane 数据，但交互范围不同。

| 能力 | Web | 桌面端 | 移动端 |
| --- | --- | --- | --- |
| Codex / OpenCode AI 会话 | 完整 | 完整 | 创建、查看、审批、停止、恢复 |
| 实例启动/停止/重启 | 支持 | 支持 | 支持 |
| 创建/删除实例 | 支持 | 支持 | 不支持 |
| 节点接入与完整管理 | 支持 | 支持 | 只读目录为主 |
| 模型、镜像和环境模板 | 支持 | 支持 | 不支持管理 |
| 应用启动和终端 | 支持 | 支持 | 支持 |
| 应用安装/卸载 | 支持 | 支持 | 不支持 |
| 仓库文件与高级 Git 管理 | 完整 | 完整 | 能力有限，复杂操作使用桌面/Web |
| Story 与自动化 | 支持 | 支持 | 支持主要流程 |
| 触发器 | 支持 | 支持 | 创建、编辑、部署和查看运行 |
| 用户、角色和登录源 | 支持 | 支持 | 不支持 |
| 移动设备会话撤销 | 支持 | 支持 | 不作为管理入口 |

桌面端使用与 Web 相同的控制面板 UI，并增加本机服务、托盘、独立窗口和桌面更新能力。

移动端的设计目标是随时查看和控制正在运行的工作，不替代完整管理员控制台。需要修改基础设施或 Secret 时回到 Web/桌面端。
