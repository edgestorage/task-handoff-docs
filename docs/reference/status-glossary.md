# 状态与术语

## 核心术语

| 术语 | 含义 |
| --- | --- |
| Control Plane | 用户界面、API 和集中配置服务 |
| Node Agent | 管理一台节点上的资源和实例生命周期 |
| Controlled Instance | 承载工作区、应用及 AI 会话的运行时 |
| AI Session | Codex 或 OpenCode 的一次受管工作会话 |
| App Session | 终端、浏览器、VS Code 等应用的一次运行会话 |
| Story | 组织文档、会话、动作和自动化的长期工作单元 |
| Provider | 提供模型 API 的连接配置 |
| Worktree | 同一 Git 仓库的独立工作目录 |

## 节点状态

- 在线：Control Plane 当前能与 Node Agent 通信；
- 离线：当前不可达，实例状态可能是缓存；
- 降级：部分能力或诊断失败，但基础连接可能仍可用。

## 实例状态

- 已创建：实例记录存在；
- 准备中：检查或拉取镜像；
- 启动中：正在启动运行环境；
- 注册中：实例服务正在连接；
- 运行中：可以创建会话；
- 停止中 / 已停止：正在结束或已结束运行；
- 不健康 / 失败：需要查看环境和结构化错误。

## AI 会话状态与阶段

状态描述整体生命周期：运行中、等待中、空闲、失败。阶段描述当前活动，例如思考、工具、编辑、等待批准或回复。

“等待中”可能表示需要审批或等待队列，不应直接关闭；“正在重连”是客户端同步状态，不表示 Agent 已停止。

## 更新状态

节点更新可能经历排队、更新 Node Agent、重启、收敛实例、成功、降级或失败。实例 runtime 可能经历排空、安装、重启和验证。

协议版本提示不一定阻止基础连接，但某项新功能可能按 capability 关闭。遇到功能缺失时先对齐 Control Plane、Node Agent 和实例版本。
